# Boss Gimmick Sprites

Coarse pixel-art sprite sheets for the boar boss stage.

- PNG with transparent backgrounds
- Horizontal strips with equal-width frames
- Nearest-neighbor filtering recommended
- `manifest.json` contains frame dimensions and state names
- `frames/` contains each state as an individual PNG
- Ground props are bottom-centered, warning/VFX frames are centered, and stopper frames share a fixed hinge pivot

The source images were generated with the built-in image generation workflow, chroma-keyed, individually segmented, palette-reduced, and resized with nearest-neighbor sampling.
